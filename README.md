# Portfolio de Christian García

Web personal hecha con HTML, CSS y JavaScript, sin dependencias.

## Estructura

```
index.html        Contenido de la página
css/style.css     Estilos y modo claro/oscuro
js/theme.js       Aplica el tema guardado al cargar
js/snippets.js    Fragmentos de código de la sección "Así escribo código"
js/main.js        Animaciones, pestañas de código, tema y repositorios de GitHub
```

## Cómo personalizarla

- **Textos, proyectos y contacto:** `index.html`
- **Colores y tipografías:** variables al inicio de `css/style.css`
- **Código de muestra:** `js/snippets.js`
